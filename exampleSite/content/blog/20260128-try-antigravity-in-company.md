在自己电脑上登录 antigravity 成功之后，遂尝试在公司电脑上也登录。用对了账号之后，根本不用挂 VPN，通过公司的专线网络直接登录，并不会收到您所在的地区不支持之类的提示。

让其帮忙写了一个小程序用于辅助工作之后，公司的网络安全部门同事给我发消息，问我这个应用是哪里下载的。

我说 Google 家的产品，我以为对方不知道是什么东西。结果并不是，对方给我发来了 antigravity 的官网，说我下载的这个没有签名，有需要的话去官网下载。

我说我就是官网下载的，然后去找了自己浏览器里的下载链接记录，比对了一下确实是官网下载。然后我查看了一下还没有删除的安装包，显示也是经过签名的。对方说那没事了，可能是安装过程中释放的文件。

此时我已经把 antigravity 卸载了，怕公司不让用。但对方也并没有说不给用，而是说建议用公司内部的那些工具。我也想用公司内部的，但我并不是研发，并没有访问 Claude Code 的权限。

可能这也解释了我的 antigravity 为何在运行过程中总是闪退，应该是触发了风控，被公司的安全软件直接杀死了。第二天我又重新安装了一次，这次根本到不了帮我写东西的时候，打开几秒钟就会闪退。卸载了事。

后来发现公司自己也推出了一个 agent 类的工具，于是申请权限，准备用一下试试，目前尚不知道申请能否通过。
