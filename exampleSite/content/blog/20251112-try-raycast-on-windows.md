 前阵子就收到了 Raycast for Wondows 的测试邀请，但是近期在家中时都没有使用 Windows 机器（搬家之后显示器一直没有拿出来），而在工地时也没顾上下载试用。今天翻收件箱的时候看到了邮件，索性在工地电脑上先下载来使用了。

前面在用的启动器是 Flow Launcher，快捷键设置为了 `Alt+Space`，而 Raycast 默认的快捷键也是这个，所以在安装之前也把 Flow Launcher 的快捷键改到 win 键上。

装好之后熟悉的感觉都回来了，在 mac 上习惯的快捷命令操作，全都可以无缝迁移。由于还是比较忙，我也没有深度体验，尝试了一下注入窗口管理等功能，没遇到什么问题。

就是最常用的启动器功能，不知道是不是刚安装好还没完成索引，对文件名的匹配效果不是很好。有一个我常用的文件，输入文件名中的关键词是找不到的，需要输入完整的文件名才行，与此同时这个关键词又能匹配出很多其他不怎么常用的文件。

不过这是小问题，相信很快就能改善。我又想起昨天写的 Blow 的那场“阻止文明的倒塌”的演讲了。不过这里并没有要吐槽 Raycast 开发团队的意思，毕竟目前只是小范围的邀请测试版本，能够做到这样的程度已经非常不错了。

Raycast 算是近些年来最令我惊喜和满意的软件，除了功能强大、免费以及用起来非常顺手之外，之前在麦可电脑上用正式版我印象里是没有遇到过 bug 的。

期待 Windows 版的正式版本能尽快发布。
